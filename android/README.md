# 자막번역 (안드로이드)

서브컴의 중국어 자막을 받아 기기 안에서 번역해 보여주는 앱입니다.
Android 8.0 이상, arm64 기기용입니다.

## 설치

1. GitHub의 **Actions → Build APK**에서 성공한 실행을 열고 **CaptionTranslator-apk**를 내려받아 압축을 풉니다.
2. `CaptionTranslator.apk`를 태블릿으로 옮겨 **내 파일**에서 누릅니다.
3. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 해당 앱에만 허용합니다. 설치 후에는 다시 꺼도 됩니다.

서명이 달라 덮어 설치가 안 되면 기존 앱을 삭제한 뒤 설치하세요.

## 사용

- 처음 실행하면 번역 언어 모델을 내려받습니다. 인터넷이 필요합니다.
- **연결** 버튼에 서브컴 IP 주소와 앱 비밀번호를 입력합니다. 같은 공유기에 있어야 합니다.
- **자막 보기 모드**는 가로 화면에 번역문을 크게 보여줍니다. 화면을 누르면 메뉴, **▲ 내역**은 지난 자막입니다.
- 앱이 켜져 있는 동안 화면이 꺼지지 않습니다.

번역은 Google ML Kit를 사용합니다. 한국어와 중국어 사이의 번역은 영어를 거치므로 어색할 수 있습니다.
AI 의역 기능은 아직 없습니다.
