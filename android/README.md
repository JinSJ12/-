# 자막번역 (안드로이드)

서브컴의 중국어 자막을 받아 기기 안에서 번역해 보여주는 앱입니다.
Android 8.0 이상, arm64 기기용입니다.

## 설치

1. GitHub의 **Actions → Build APK**에서 성공한 실행을 열고 **CaptionTranslator-apk**를 내려받아 압축을 풉니다.
2. `CaptionTranslator.apk`를 태블릿으로 옮겨 **내 파일**에서 누릅니다.
3. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 해당 앱에만 허용합니다. 설치 후에는 다시 꺼도 됩니다.

서명이 달라 덮어 설치가 안 되면 기존 앱을 삭제한 뒤 설치하세요.

## 사용

- 처음 실행하면 번역 언어 모델을 내려받습니다. 인터넷이 필요합니다.
- **연결** 버튼에 서브컴 IP 주소와 앱 비밀번호를 입력합니다. 같은 공유기에 있어야 합니다.
- **자막 보기 모드**는 가로 화면에 번역문을 크게 보여줍니다. 화면을 누르면 메뉴, **▲ 내역**은 지난 자막입니다.
- 앱이 켜져 있는 동안 화면이 꺼지지 않습니다.

번역은 Google ML Kit를 사용합니다. 한국어와 중국어 사이의 번역은 영어를 거치므로 어색할 수 있습니다.

## AI 의역

1. 첫 화면의 **AI** 버튼에서 모델을 고르고 **내려받고 켜기**를 누릅니다. Wi-Fi를 권하며 끝날 때까지 앱을 열어 둡니다.
2. 문장이 들어오면 기본 번역이 먼저 나오고, 의역이 끝나면 큰 글씨가 의역으로 바뀝니다.
   AI 화면의 **기본 번역을 크게 보기**를 켜면 기본 번역이 크게, 의역이 작게 표시됩니다.
   Gemma와 Hy-MT2는 원문을 직접 번역하고, Qwen은 기본 번역의 말투만 다듬습니다.

   | 모델 | 방식 | 참고 |
   |---|---|---|
   | Qwen3.5 2B (기본), Qwen3 1.7B | 말투 다듬기 | 아이폰 앱과 같은 방식 |
   | Hy-MT2 1.8B | 번역 전용 | CPU로 실행. 제작사의 맞춤 요청 형식으로 뜻 보존과 구어체를 요청. 모델 카드의 라이선스는 Apache 2.0 |
   | Gemma 4 E2B | 직접 번역 | 안드로이드에만 있음 |

   아이폰의 TranslateGemma는 안드로이드용 공개 파일을 찾지 못해 넣지 않았습니다.
3. 상태에 GPU 또는 CPU가 표시됩니다. CPU는 느립니다.
4. 앱이 느려지거나 종료되면 더 작은 모델을 고르거나 끄세요.

모델은 Hugging Face의 `litert-community`에서 내려받으며 각 모델의 라이선스를 따릅니다.
실행에는 LiteRT-LM을 사용합니다. 의역은 태블릿 안에서 처리됩니다. 받은 모델은 앱을 삭제하면 함께 지워집니다.
