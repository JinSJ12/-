# 자막번역 (아이폰 자막 앱)

중국어 문장을 아이폰 안에서 한국어로 번역하고 크게 보여주는 앱입니다.
iOS 18 이상이 필요합니다. 서브컴의 자막 서버에 연결하면 통화 내용이 자동으로 표시됩니다.

## 1. GitHub에서 빌드하기

1. GitHub에 로그인하고 새 저장소를 만듭니다.
   비공개 저장소의 macOS 빌드는 무료 사용 시간을 빠르게 소모하니 한도를 확인하세요.
2. 이 폴더의 내용 전체를 저장소의 최상위에 올립니다. `.github` 폴더도 꼭 포함해야 합니다.
3. 저장소의 **Actions** 탭 → **Build IPA** → **Run workflow**를 누릅니다.
4. 빌드가 성공하면 실행 결과 아래의 **CaptionTranslator-ipa**를 내려받아 압축을 풉니다.

## 2. PC에서 아이폰에 설치하기

1. Apple 홈페이지에서 받은 **iTunes와 iCloud**를 설치합니다.
   Microsoft Store 버전은 Sideloadly에서 동작하지 않으므로, 있다면 먼저 제거합니다.
2. [sideloadly.io](https://sideloadly.io)에서 Sideloadly를 설치합니다.
3. 아이폰을 USB로 연결하고, 아이폰에 뜨는 "이 컴퓨터를 신뢰"를 허용합니다.
4. Sideloadly에 `.ipa` 파일을 넣고 Apple ID를 입력해 설치합니다.
   외부 업체 도구에 로그인하는 것이므로 별도의 Apple ID를 권합니다.
5. 아이폰에서 `설정 → 개인정보 보호 및 보안 → 개발자 모드`를 켜고 재시동합니다.
6. `설정 → 일반 → VPN 및 기기 관리`에서 본인 Apple ID 항목을 신뢰합니다.

무료 Apple ID로 설치한 앱은 **7일 뒤에 만료**됩니다. 같은 방법으로 다시 설치하세요.

## 3. 시험하기

1. 앱을 처음 열고 언어팩 다운로드 안내가 나오면 허용합니다.
2. 아래의 예문 버튼을 누르거나 중국어를 입력합니다.
3. 번역 품질과 표시되는 처리 시간을 확인합니다.
4. 언어팩 설치 후 비행기 모드에서도 번역되면 기기 내 번역이 동작하는 것입니다.

## 4. 서브컴에 연결하기

1. 서브컴에서 자막 서버를 실행합니다.
2. 앱의 **연결** 버튼에서 서브컴 IP 주소와 앱 비밀번호를 입력합니다.
3. "로컬 네트워크" 접근 요청을 허용합니다.

연결되면 시험용 예문은 숨겨집니다. 서버에서 이름 없이 온 문장이 방금 번역한 결과와 같으면
되돌아온 것으로 보고 무시합니다.

## 5. 자막 보기 모드

**자막 보기 모드** 버튼을 누르면 가로 화면으로 바뀌고 번역문이 가운데에 크게 표시됩니다.
지난 자막 내역은 평소에 접혀 있습니다. 하단의 **내역** 버튼을 누르면 화면 전체를 덮으며 올라오고,
**내역 닫기**를 누르면 다시 접힙니다. 그 밖의 화면을 누르면 닫기, 글자 크기, 원문 보기 메뉴가 나옵니다.

## 6. 양방향 번역

문장에 한글이 있으면 한국어 → 중국어, 없으면 중국어 → 한국어로 번역합니다.
첫 화면의 입력창에 한국어를 입력하면 중국어 번역문과 **중국어 복사** 버튼이 나옵니다.
서브컴은 아직 본인의 음성을 인식하지 않습니다.

## 아이폰 AI 의역

1. 첫 화면의 **AI** 버튼에서 모델을 고르고 **내려받고 켜기**를 누릅니다. Wi-Fi를 권하며,
   끝날 때까지 앱을 열어 둡니다.
2. 문장이 들어오면 애플 번역이 먼저 나오고, 의역이 끝나면 큰 글씨가 의역으로 바뀝니다.
   첫 화면에는 비교할 수 있게 애플 번역도 작게 남습니다.
3. 의역이 밀리면 오래된 문장은 애플 번역만 표시합니다.
4. 앱이 느려지거나 종료되면 더 작은 모델을 고르거나 끄세요.

| 모델 | 용도 | 참고 |
|---|---|---|
| Qwen3.5 2B, Qwen3 1.7B | 범용 | 직접 번역하지 않고 애플 번역의 말투만 다듬게 합니다 |
| Hy-MT2 1.8B (8비트, 4비트) | 번역 전용 | Apache 2.0. 구어체를 요청하지만 반영 정도는 확인이 필요합니다 |
| TranslateGemma 4B | 번역 전용 | Gemma 이용 약관. 말투를 지정할 수 없고 메모리를 많이 씁니다 |

AI는 뜻을 바꿀 수 있습니다. **AI** 화면의 **애플 번역을 크게 보기**를 켜면 애플 번역이 크게,
AI 의역이 작게 표시됩니다.

모델을 바꾸려면 끈 뒤 다른 모델을 골라 켭니다. 내려받은 모델은 저장 공간을 차지합니다.
`HY-MT1.5`는 라이선스가 한국을 제외하므로 넣지 않았습니다.

모델은 Hugging Face의 `mlx-community`에서 내려받으며, 각 모델의 라이선스를 따릅니다.
실행에는 MLX Swift LM을 사용합니다. 의역은 인터넷 없이 아이폰 안에서 처리됩니다.

## 7. 본 PC로 번역 결과 보내기 (준비 기능)

기본 화면에서 서브컴에 연결되어 있으면, 번역이 끝난 문장을 서브컴으로 보냅니다.
서브컴 서버가 이를 본 PC의 수신 앱에 전달합니다. 자막 보기 모드에서는 보내지 않습니다.
